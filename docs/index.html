1초급 VSS 타임라인 복구와 샌드박스 가드로 PC를 타임머신처럼 되돌리세요.

최신 버전 다운로드 (.zip) 프리미엄 구매 (Stripe) GitHub 저장소

Windows 데스크톱 앱입니다. zip을 OneDrive 밖(예: C:\Apps\SandboxTimeline)에 풀고 관리자 권한으로 실행하세요.

주요 기능

⏪ VSS 타임라인

스냅샷을 찍고 슬라이더로 과거 시점을 선택해 즉시 롤백합니다.

🛡️ 샌드박스 가드

다운로드 폴더의 의심 실행 파일을 Windows Sandbox에서 안전하게 격리 실행합니다.

⌨️ 전역 단축키

Ctrl + Win + Z 로 어디서든 메인 창을 엽니다.

🔒 Vault 라이선스

클라이언트에 비밀키 없이 서버 Vault로 프리미엄을 검증합니다.

설치 방법

  1. 위 최신 버전 다운로드로 zip 받기
  2. C:\Apps\SandboxTimeline\ 등 로컬 폴더에 압축 해제 (OneDrive 비권장)
  3. SandboxTimeline.exe 우클릭 → 관리자 권한으로 실행
  4. SmartScreen → 추가 정보 → 실행
  5. 프리미엄은 프리미엄 구매 후 라이선스 키를 앱에 입력

상세 설치 가이드 (INSTALL-ko.md)

시스템 요구 사항

  • Windows 11 (또는 Windows 10 22H2+)
  • 64비트(x64), 관리자 권한(UAC)
  • Volume Shadow Copy Service 활성화
  • Windows Sandbox (샌드박스 가드, Windows 11 Pro 이상 — Home은 타임라인만)
