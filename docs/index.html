Microsoft Store에서 설치 · 프리미엄 GitHub 저장소

Microsoft Store에서 설치하세요. 프리미엄($3.99/월)은 앱 안에서 Store 구독으로 활성화됩니다.

주요 기능

⏪ VSS 타임라인

스냅샷을 찍고 슬라이더로 과거 시점을 선택해 즉시 롤백합니다.

🛡️ 샌드박스 가드

다운로드 폴더의 의심 실행 파일을 Windows Sandbox에서 안전하게 격리 실행합니다.

⌨️ 전역 단축키

Ctrl + Win + Z 로 어디서든 메인 창을 엽니다.

🔒 Microsoft Store 프리미엄

Store 구독으로 스냅샷 한도와 샌드박스 가드를 해제합니다. 라이선스 키 입력 없음.

설치 방법

  1. Microsoft Store에서 Sandbox Timeline 설치
  2. 시작 메뉴에서 실행 → UAC(관리자) 예
  3. 프리미엄: 앱에서 Microsoft Store에서 구독 ($3.99/월)

Store 배포 가이드 (개발자용) · 개인정보 처리방침

시스템 요구 사항

  • Windows 11 (또는 Windows 10 22H2+)
  • 64비트(x64), 관리자 권한(UAC)
  • Volume Shadow Copy Service 활성화
  • Windows Sandbox (샌드박스 가드, Windows 11 Pro 이상 — Home은 타임라인만)
