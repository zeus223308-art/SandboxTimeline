# Privacy Policy — Sandbox Timeline

Last updated: 2026-06-04

## Overview

Sandbox Timeline ("the app") is a Windows desktop utility for VSS-based system snapshots and optional sandbox guard features. This policy describes data handled on your PC and through Microsoft Store.

## Data stored locally

- Snapshot metadata and backup files on your computer
- Encrypted local settings (including premium entitlement state from Microsoft Store)
- Startup diagnostic logs under `C:\ProgramData\SandboxTimeline\` (if enabled)

The app does not upload your files or snapshots to our servers.

## Microsoft Store purchases

Premium subscriptions are sold through **Microsoft Store**. Payment and account data are processed by Microsoft under the [Microsoft Privacy Statement](https://privacy.microsoft.com/). The app queries Microsoft Store APIs on your device to verify an active subscription.

## Network use

- Microsoft Store license validation (Store builds)
- Optional app update checks (if enabled)
- No third-party payment servers (Stripe) in Store builds

## Contact

Support: use the email listed on the Microsoft Store listing or your GitHub repository contact.

## Changes

We may update this policy. The latest version is published with the app listing and documentation site.
